Stop Losing
Context Between
AI Tools.

AI coding assistants forget everything when you close the terminal. This open-source toolkit writes session summaries from Claude Code, Antigravity, Cursor, Windsurf, Aider, Cline, and Copilot into a single Obsidian vault using the PARA method. When you switch tools, the new agent reads the vault and picks up where the last one stopped.

Setup & Integration

Per-Tool Config

Claude Code (CLI Hook)

Claude Code has a built-in SessionEnd hook. When you exit a session, the hook runs vault-sync.mjs. It reads the raw .jsonl transcript, condenses it via condense(), and spawns a headless claude -p to write the summary into your Obsidian vault's 01_Projects/ folder.

// ~/.claude/settings.json → hooks.SessionEnd → "node vault-sync.mjs"

Google Antigravity IDE (Skill)

Antigravity is a persistent IDE — it doesn't emit session-end events. Instead, you install a native Antigravity Skill. Type /vault-sync in the chat; the agent reads its own transcript, summarizes the session, and writes directly to your vault using its file operation tools.

// Copy SKILL.md → ~/.gemini/config/skills/vault-sync/

Cursor, Windsurf, Aider, Cline, Copilot

These tools use prompt injection through their config files (.cursorrules, .windsurfrules, .clinerules, or VS Code instructions). The injected system rule tells the agent to write a session summary to your vault path as its final step after completing a task.

// Copy the example file from each tool's folder into your project root
