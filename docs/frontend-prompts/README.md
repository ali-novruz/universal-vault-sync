# Frontend Prompts

Prompts used to build the project website ([universal-vault-sync.vercel.app](https://universal-vault-sync.vercel.app)). They are not part of the vault-sync skills and you don't need them to use the toolkit.

- `MASTER_PROMPT.md`: full frontend spec in one prompt
- `PHASE_BY_PHASE_PROMPTS.md`: the same spec split into standalone phase prompts
- `phases/`: each phase as its own file
