## 1. PROJECT VISION & STRATEGIC OVERVIEW

**Universal AI Vault Sync** is an open, cross-agent persistent memory protocol designed to eliminate the critical "state amnesia" problem across distinct AI coding environments. Currently, AI coding assistants (**Claude Code CLI, Google Antigravity IDE, Cursor, Windsurf, Aider, Cline, and GitHub Copilot**) operate in isolated memory silos, losing context, architectural rationale, and execution history once a session terminates.

This frontend application serves as the **flagship visual interface, live interactive telemetry dashboard, and functional demonstration sandbox** for the Universal Vault Sync protocol. It connects all participating AI tools to a centralized, decentralized Markdown/Obsidian Knowledge Vault structured around the industry-standard **PARA methodology (Projects, Areas, Resources, Archives)**.
